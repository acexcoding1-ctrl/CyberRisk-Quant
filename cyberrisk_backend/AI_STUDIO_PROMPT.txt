Integrate the existing CyberRisk Quant React/Vite dashboard with a FastAPI backend without changing the current UI design, layout, navigation, styling, charts or responsiveness.

Backend base URL:
http://localhost:8000

API endpoints:
GET /api/dashboard
GET /api/assets
GET /api/vulnerabilities
GET /api/controls
GET /api/risks
GET /api/risk/{asset_id}
GET /api/optimization/recommendations?budget_usd=180000
POST /api/risk/quantify
POST /api/optimization
GET /api/health

Integration requirements:
1. Replace hardcoded dashboard values with real API data.
2. Keep the existing UI exactly as much as possible.
3. Create one centralized API service such as src/services/api.ts.
4. Use VITE_API_BASE_URL with default value http://localhost:8000.
5. Dashboard KPI cards must use /api/dashboard.
6. Risk/asset tables must use /api/assets and /api/risks.
7. Asset detail panels must use /api/risk/{asset_id}.
8. Optimization and mitigation sections must use the optimization API.
9. ROSI must come from the backend response instead of being separately calculated in React.
10. Add loading, error and empty states.
11. Do not duplicate risk-engine/business logic inside React.
12. Do not create another backend.
13. Keep the architecture ready for future real CVE, CISA KEV and MITRE ATT&CK integrations.
14. Never expose API secrets in frontend code.
